MEDIQR — SITE DE DÉMONSTRATION

Fichier principal : index.html

Pour le publier avec GitHub Pages :
1. Crée un nouveau dépôt public nommé mediqr-site.
2. Ouvre le dépôt et choisis Add file > Upload files.
3. Téléverse index.html (pas le ZIP).
4. Clique sur Commit changes.
5. Va dans Settings > Pages.
6. Dans Build and deployment, choisis Deploy from a branch.
7. Choisis Branch: main et Folder: / (root), puis Save.
8. Attends quelques minutes et récupère le lien affiché dans Settings > Pages.

Le site est un prototype de classe. Les abonnements, prix et services sont fictifs.
Ne publie jamais de vraies informations médicales ou données personnelles.
Les boutons d'abonnement sont seulement décoratifs et ne prennent pas de paiement.
